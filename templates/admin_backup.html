Render Cloud Deployment Persistence Guidelines

By default, Render Free Tier web services use ephemeral containers that refresh during restarts. Sabro Vision solves this automatically:

  • Built-in Data Vault: All subscriber keys, logins, and settings are written into data_vault.json with WAL checkpointing on every write.
  • Render Persistent Disk (Recommended for Production): Attach a persistent disk mounted at /var/data and set environment variable DATABASE_PATH=/var/data/sabro_iptv.db.
  • GitHub Auto-Sync: If you set GITHUB_TOKEN in Render environment variables, Sabro Vision automatically commits new data snapshots back to your GitHub repository!
